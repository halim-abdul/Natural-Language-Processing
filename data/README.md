# Data

The original coursework datasets are not committed here because several CSV files are large and may be subject to course/distribution constraints.

Place the SST, QQP, STS and ETPC files here using the filenames expected by `datasets.py`:

- `sst-sentiment-train.csv`, `sst-sentiment-dev.csv`, `sst-sentiment-test-student.csv`
- `quora-paraphrase-train.csv`, `quora-paraphrase-dev.csv`, `quora-paraphrase-test-student.csv`
- `sts-similarity-train.csv`, `sts-similarity-dev.csv`, `sts-similarity-test-student.csv`
- `etpc-paraphrase-train.csv`, `etpc-paraphrase-detection-test-student.csv`, `etpc-paraphrase-generation-test-student.csv`
